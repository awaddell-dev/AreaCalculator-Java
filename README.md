\# Java Area Calculator (OOP)



A Java console application that calculates the area of basic geometric shapes using object-oriented programming principles.



\## Features



\- Calculates area for circles, squares, and rectangles

\- Uses inheritance and polymorphism

\- Input validation for numeric values

\- Clean Maven project structure



\## Concepts Demonstrated



\- Abstraction (Shape as an abstract class)

\- Inheritance (Circle, Square, Rectangle extend Shape)

\- Polymorphism (single Shape reference, multiple implementations)

\- Encapsulation (controlled access to fields)
